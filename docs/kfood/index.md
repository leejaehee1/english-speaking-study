## 2. 한식 조리법 필수 영어 표현 사전 (이것만 알면 한식 50가지 설명 끝!)

굵은 영어 표현을 클릭하면 원어민 발음과 발음 기호(IPA)를 바로 들을 수 있습니다.

### ① 한식 8대 핵심 양념 (Korean Pantry Essentials)

| 한국어 양념 | 원어민이 바로 이해하는 영어 표현 | 소리 블록 예문 |
| :--- | :--- | :--- |
| **고추장** | **gochujang (Korean red chili paste)** | **I'm gonna add a spoon of gochujang.** |
| **고춧가루** | **red pepper flakes (gochugaru)** | **We have to put some red pepper flakes.** |
| **된장** | **soybean paste (doenjang)** | **I'll dissolve the soybean paste in water.** |
| **간장 (진간장/국간장)** | **soy sauce / soup soy sauce** | **Just add a splash of soy sauce.** |
| **참기름 / 들기름** | **sesame oil / perilla oil** | **Finish with a drop of sesame oil.** |
| **다진 마늘** | **minced garlic** | **Koreans always use a lot of minced garlic!** |
| **대파** | **green onion (scallion)** | **I'll chop the green onion.** |
| **통깨 (참깨)** | **sesame seeds** | **Sprinkle some sesame seeds on top.** |

### ② 한식 10대 조리 동작 코어 블록 (Cooking Action Chunks)

| 한식 조리법 | 핵심 코어 블록 | 발음 리듬 포인트 |
| :--- | :--- | :--- |
| **한 입 크기로 썰다** | **cut ~ into bite-sized pieces** | `컷 인투 바잇-사이즈드 피시즈` |
| **고기를 양념에 재우다** | **marinate the meat** | `매리네잇 더 밋` (`for 30 minutes`와 짝꿍) |
| **센 불에 달달 볶다** | **stir-fry on high heat** | `스터-프라이 온 하이 힛` |
| **팔팔 끓이다** | **bring it to the boil** | `브링 잇 투 더 보일` |
| **약불에 푹(뭉근히) 끓이다** | **let it simmer** | `레릿 시머` (`let it` 플랩화) |
| **나물을 데치다** | **blanch the vegetables** | `블랜치 더 베지터블즈` |
| **나물을 조물조물 무치다** | **season and toss by hand** | `시즌 앤 토스 바이 핸드` |
| **전을 노릇바삭하게 부치다** | **pan-fry until golden and crispy** | `팬-프라이 언틸 골든 앤 크리스피` |
| **상추에 쌈을 싸다** | **wrap it in lettuce** | `랩 잇 인 레터스` (`make a lettuce wrap`) |
| **국물 한 모금 / 음식 한 입 맛보다** | **take a sip / take a bite** | `테이커 씹` / `테이커 바이트` |

## 3. [V2 업그레이드] 소리 블록 조합 훈련 & 1080p 방송국급 유튜브 워크플로우

### 🔠 휴대폰 모바일 가독성 최적화 (글자 크기 조절 기능)
- **기본 글자 크기 대형화**: 스마트폰 작은 화면이나 9:16 세로형 쇼츠(Shorts)에서도 글자가 시원시원하게 보이도록 기본 폰트를 **‘📱 대형(모바일 추천)’** 으로 대폭 키웠습니다.
- **원클릭 글자 크기 전환**: 상단 우측의 **`🔠 글자: 📱 대형 / 👑 초대형 / 보통`** 버튼을 누르면 언제든지 원하는 크기로 즉시 조절할 수 있습니다.
- **고대비 네온 자막**: 어두운 요리 사진 위에서도 자막이 묻히지 않도록 깊은 블랙 글래스 배경과 고대비 텍스트 섀도를 기본 적용했습니다.

### 🧩 2-Stage 소리 블록 조합 훈련 시스템
단순히 완성된 문장을 나눠 읽는 것이 아니라, **레고 블록을 직접 갈아 끼우고 합체하는 손맛과 뇌 훈련** 을 제공합니다:

1. **🔄 1단계: 시작 블록 3단 교체 훈련 (Block Swap)**
   - 가운데 **② 코어 블록(예: `[make Kimchi stew]`)** 은 고정해 둡니다.
   - 앞의 **① 시작 블록** 만 3가지로 바꿔 끼우며 뜻이 어떻게 달라지는지 체감합니다:
     - Combo 1: **`[I'm gonna]`** + `[make Kimchi stew]` → *“나 김치찌개 끓일 거야.”* (의지)
     - Combo 2: **`[I wanna]`** + `[make Kimchi stew]` → *“나 김치찌개 끓이고 싶어.”* (희망)
     - Combo 3: **`[Do you wanna]`** + `[make Kimchi stew]?` → *“너 김치찌개 끓일래?”* (제안/질문)
   - 각 콤보 카드를 터치하면 해당 조합 발음과 한국어 의미가 즉시 재생됩니다.

2. **🧲 2단계: 실전 자석 합체 미션 (Magnet Snap Quiz)**
   - 한국어 미션 음성: *“실전 조립 미션! 오늘 저는 김치찌개를 끓일 거예요. 블록 세 개를 합쳐 보세요!”*
   - 화면에 떠 있는 후보 블록 중 정답 블록들이 중앙 슬롯으로 **‘철컥!’** 날아와 자석처럼 합체되는 다이내믹 연출!

3. **🎤 3단계: 완성 문장 따라 말하기 (YOUR TURN)**
   - 딩동 신호음과 함께 4초 카운트다운 동안 마이크로 크게 발화하는 섀도잉 훈련.

### 🎥 유튜브 녹화 가이드 (1080p Full HD 고화질)
1. **🖥️ 1080p 풀스크린 방송 모드 진입**:
   - 스튜디오 우측 상단의 초록색 **`🖥️ 1080p 풀스크린 방송 모드`** 버튼을 누르면 브라우저 메뉴가 사라지고 모니터 전체가 꽉 찬 방송 화면으로 전환됩니다.
2. **전체 화면 녹화 시작 (`Cmd + Shift + 5`)**:
   - 화면 일부를 작게 드래그해서 녹화하면 해상도가 떨어집니다. 맥북 단축키 `Cmd + Shift + 5`에서 **‘전체 화면 기록(Record Entire Screen)’** 을 선택해 녹화하세요.
3. **▶️ 전체 장면 자동 방송**:
   - 화면 우측 하단 미니 리모컨에서 **`▶️ 전체 자동 방송 시작`** 을 누르면 인트로 → 8개 장면 풀코스(3단 교체 → 자석 합체 → 따라 말하기) → 아웃트로까지 원테이크로 매끄럽게 진행됩니다.
