# WORK

핵심 느낌: **일하다, 작업하다, 작동하다, 효과가 있다**. 뒤에 오는 전치사로 역할·프로젝트·분야·회사·도구를 구체적으로 설명합니다.

## 개발자로 내 일을 설명하기

### Work as — 어떤 역할로 일하는지

`work as + 직업·역할`로 직업을 말합니다. 단수 직업명 앞에는 보통 `a/an`을 붙입니다.

- **I work as an IT developer.** — IT 개발자로 일해요.
- **I work as a software engineer.** — 소프트웨어 엔지니어로 일해요.
- **I work as a backend developer.** — 백엔드 개발자로 일해요.

가볍게 자기소개할 때는 **I’m a software developer.**도 자연스럽습니다.

### Work on — 어떤 프로젝트나 과제를 하는지

`work on + 프로젝트·시스템·과제`로 작업 대상을 말합니다. 요즘 진행 중인 일은 `I’m working on ...`으로 설명합니다.

- **I’m working on a new mobile app.** — 요즘 새 모바일 앱을 개발하고 있어요.
- **We’re working on the backend system.** — 백엔드 시스템을 작업 중이에요.
- **I’m working on AI models.** — AI 모델 관련 작업을 하고 있어요.
- **I’m working on fixing a bug.** — 버그를 고치는 중이에요. `work on + 동사-ing`

프로젝트는 `work on`, 사용하는 언어·도구는 아래의 `work with`로 말하면 구분하기 쉽습니다.

### Work in — 어떤 분야나 부서에서 일하는지

`work in + 산업·분야·부서`로 일하는 영역을 말합니다.

- **I work in the IT industry.** — IT 업계에서 일해요.
- **He works in web development.** — 그는 웹 개발 분야에서 일해요.
- **I work in the cloud department.** — 클라우드 부서에서 일해요.

언어를 말할 때 **I work in Java.**도 가능하지만, 사용하는 기술을 소개할 때는 **I work with Java.** 또는 **I develop software in Java.**라고 말할 수 있습니다.

### Work for / at — 어느 회사나 고객을 위해 일하는지

`work for + 회사·고객`은 고용주나 서비스를 제공하는 대상을, `work at + 회사·직장`은 일하는 곳을 말합니다. 회사 이름에는 둘 다 쓸 수 있습니다.

- **I work at Google as a developer.** — 구글에서 개발자로 일해요.
- **I work for a startup.** — 스타트업에서 일해요.
- **I work for several clients as a freelancer.** — 프리랜서로 여러 고객의 일을 해요.

고객과 협업한다는 점을 강조하려면 **I work with several clients.**라고 말합니다.

### Work with — 어떤 도구를 쓰고 누구와 협업하는지

`work with + 언어·도구·사람`으로 사용하는 기술이나 협업 상대를 말합니다.

- **I mainly work with Java and Spring.** — 주로 Java와 Spring을 사용해요.
- **I work with designers and other developers.** — 디자이너와 다른 개발자들과 함께 일해요.

## 짧은 자기소개로 연결하기

**I work for a startup as a software engineer.** — 스타트업에서 소프트웨어 엔지니어로 일해요.

**I work in web development, mainly with Java and Spring.** — 웹 개발 분야에서 일하고, 주로 Java와 Spring을 사용해요.

**I’m currently working on a new backend system.** — 현재 새 백엔드 시스템을 개발하고 있어요.

평소 직업·업무는 `I work ...`, 현재 진행 중인 프로젝트는 `I’m working on ...`으로 말합니다.

## 일상에서도 바로 쓸 문장

- **I’m working on my English.** — 영어 실력을 키우려고 노력 중이에요.
- **My phone isn’t working.** — 휴대폰이 작동하지 않아요.
- **This solution works well.** — 이 해결책은 효과가 좋아요.
- **Does Friday work for you?** — 금요일 괜찮으세요? 일정이 맞는지 묻습니다.
- **That works for me.** — 저는 그렇게 하면 좋아요. 제안이나 일정에 동의할 때 씁니다.

`I work for a startup.`의 `work for`는 일하는 대상이고, `Friday works for me.`는 일정이 나에게 맞는다는 뜻입니다.

## 내 상황으로 연습

아래 빈칸을 채우고, 내 일을 3문장으로 소개해보세요.

1. `I work as a/an ___.` — 내 역할
2. `I work for ___ / at ___.` — 회사·고객
3. `I work in ___.` — 분야·부서
4. `I mainly work with ___.` — 사용하는 기술
5. `I’m currently working on ___.` — 진행 중인 프로젝트

연습 질문: **What do you do?** — 무슨 일을 하세요?

추가 질문: **What are you working on these days?** — 요즘 어떤 일을 하고 계세요?
