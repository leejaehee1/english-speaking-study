# WORK

핵심 느낌: **일하다, 작동하다, 효과가 있다**.

## 바로 쓸 문장

- **I work at a software company.** — 소프트웨어 회사에서 일해요. `work at + 직장`
- **I’m working on my English.** — 영어 실력을 키우려고 노력 중이에요. `work on + 과제·목표`
- **My phone isn’t working.** — 휴대폰이 작동하지 않아요.
- **Does Friday work for you?** — 금요일 괜찮으세요? 일정이 맞는지 묻습니다.

## 내 상황으로 연습

`I work at ___.`로 직장을, `I’m working on ___.`로 요즘 집중하는 것을 말합니다.

**That works for me.** — 저는 그렇게 하면 좋아요. 제안이나 일정에 동의할 때 씁니다.
