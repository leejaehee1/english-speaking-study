# 외국어 학습법 · 소리와 표현 쌓기

출처: [유튜브 영상](https://www.youtube.com/watch?v=xlez1dS9lAU) · 약 28분, 첨부 스크립트 기준 요약

## 강사의 핵심 주장

- **소리 익히기:** 음소·발음을 연습하고, 짧고 쉬운 문장을 듣고 따라 말하며 쉐도잉으로 소리와 리듬에 익숙해진다. **쉐도잉만으로 회화가 완성되지는 않는다.** 자기 생각을 문장으로 만드는 연습도 필요하다.
- **표현 쌓기:** 영상의 상황과 한국어 자막을 보고, 영어를 확인하기 전에 직접 말해 본다. 실제 대사를 듣고 비교하며 새로운 **Chunk(통째로 꺼내 쓸 표현 덩어리)**를 익힌 뒤, 같은 상황을 보고 다시 말한다. 실제 대사만 정답인 것은 아니다.
- **자료 선택:** 초급 회화 → 애니메이션 → 일상 영화·로맨틱 코미디 → 관심 분야 TED로 범위를 넓힌다. 자신이 알고 있고 말하고 싶은 주제를 고른다.

소리가 어렵다면 소리 훈련부터, 소리는 익숙하지만 할 말이 떠오르지 않는다면 표현 쌓기부터 시작한다.

## 우리 스터디 적용 루틴 · 별도 학습 제안

**상황 파악 → 영어 직접 만들기 → 실제 표현 확인 → Chunk/발음 정리 → 다시 듣고 말하기**

짧은 장면 하나로 연습하고, 배운 Chunk를 내 일상에 맞게 바꿔 말한다. 다음 복습 때는 영어 대사를 가리고 상황만 보고 다시 말해 본다.
