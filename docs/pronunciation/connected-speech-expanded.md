# 발음하기 어려운 표현 60개 · 연결 발화 확장

짧은 기능어의 연속, 자음 충돌, 연음·약화·축약을 연습하는 자료입니다. 대화에서 제공한 영어 60문장과 한국어 뜻을 원문 그대로 보존했습니다.

## 앞선 if 중심 자료와의 구분

앞서 요청한 자료는 Level 1 if 연결 → Level 2 짧은 단어 연속 → Level 3 복합 연결 → Level 4 고속 연결 구성입니다. 이번 자료는 짧은 단어 연속 → it/if/is/as 연결 → 자음 충돌 → 빠른 실전 회화로 범위를 넓힌 별도 세트입니다. if가 포함된 문장도 학습 목적상 유지합니다.

2026-10-17 로컬 저장소의 전체 추적 문서와 발음 폴더를 확인했으나, 앞선 if 중심 60문장 자료는 없었습니다. 이전 대화에도 커밋·푸시 미완료로 기록되어 있습니다. 이전 자료의 60문장 전체는 대화의 훈련 카드에서 확인되지 않아 문장별 완전 중복 여부는 확정할 수 없습니다. 확인 가능한 앞선 연결 패턴 예문 8개와 이번 60문장 사이에는 완전히 동일한 문장이 없습니다. 이번 자료로 이전 자료를 대체하지 않습니다.

## Level 1. 짧은 단어가 연속되는 표현

짧은 단어를 하나씩 발음하기보다 의미 덩어리로 묶는 훈련

| 영어 표현 | 의미 |
|--------|--------|
| 1\. What do you mean? | 무슨 뜻이야? |
| 2\. How do you know? | 어떻게 알아? |
| 3\. What did you do? | 뭐 했어? |
| 4\. Where did you go? | 어디 갔어? |
| 5\. What are you up to? | 뭐 하고 있어? |
| 6\. How did it go? | 어떻게 됐어? |
| 7\. What is it about? | 무슨 내용이야? |
| 8\. Do you want me to? | 내가 해줄까? |
| 9\. Is that what you mean? | 그게 네 말이야? |
| 10\. How am I supposed to know? | 내가 그걸 어떻게 알아? |
| 11\. What do I do now? | 이제 어떻게 하지? |
| 12\. Who do you think you are? | 네가 뭐라도 되는 줄 알아? |
| 13\. Why would I do that? | 내가 왜 그러겠어? |
| 14\. What are we going to do? | 우리 이제 어떻게 하지? |
| 15\. How long have you been here? | 여기 온 지 얼마나 됐어? |

## Level 2. `it`, `if`, `is`, `as` 연결

이 단계가 현재 어려워하는 부분과 가장 가깝습니다.

| 영어 표현 | 의미 |
|--------|--------|
| 16\. Is it okay if I go? | 내가 가도 괜찮아? |
| 17\. What if it doesn't work? | 그게 작동하지 않으면? |
| 18\. I don't know if it's worth it. | 그럴 가치가 있는지 모르겠어. |
| 19\. Let me see if it works. | 작동하는지 확인해 볼게. |
| 20\. Is it as good as it looks? | 보기만큼 좋아? |
| 21\. If it is, it is. | 그렇다면 그런 거지. |
| 22\. As far as I know, it is. | 내가 알기로는 그래. |
| 23\. It's not as easy as it sounds. | 말처럼 쉽지 않아. |
| 24\. Even if it is, I don't care. | 그렇다 해도 상관없어. |
| 25\. What if I don't want to? | 내가 원하지 않으면? |
| 26\. I wonder if it's possible. | 그게 가능할지 궁금해. |
| 27\. See if you can figure it out. | 알아낼 수 있는지 해봐. |
| 28\. If I were you, I'd wait. | 내가 너라면 기다릴 거야. |
| 29\. It is what it is. | 어쩔 수 없지. |
| 30\. I don't know what it is yet. | 아직 그게 뭔지 모르겠어. |

## Level 3. 자음 충돌과 연결 발음

한국어 화자가 자음 사이에 불필요한 모음을 넣거나 입을 크게 움직이기 쉬운 표현입니다.

| 영어 표현 | 의미 |
|--------|--------|
| 31\. Next time, let me know. | 다음에는 알려줘. |
| 32\. I asked him to help. | 그에게 도와달라고 했어. |
| 33\. Just give me a second. | 잠깐만 기다려 줘. |
| 34\. I think that's right. | 그게 맞는 것 같아. |
| 35\. What's the best way to do it? | 가장 좋은 방법이 뭐야? |
| 36\. I should've told you. | 너한테 말했어야 했는데. |
| 37\. I must've missed it. | 내가 놓쳤나 봐. |
| 38\. That's exactly what I meant. | 바로 그 말이야. |
| 39\. I didn't expect that. | 그건 예상 못 했어. |
| 40\. It's the first time I've heard that. | 그 말은 처음 들어. |
| 41\. I can't stand it anymore. | 더 이상 못 참겠어. |
| 42\. I used to think so. | 예전에는 그렇게 생각했어. |
| 43\. What's going on with that? | 그건 어떻게 된 거야? |
| 44\. I haven't had a chance yet. | 아직 기회가 없었어. |
| 45\. It doesn't make sense to me. | 난 이해가 안 돼. |

## Level 4. 빠른 실전 회화 문장

짧은 기능어와 다양한 연결이 한 문장에 여러 번 등장합니다.

| 영어 표현 | 의미 |
|--------|--------|
| 46\. I don't know what you want me to do. | 네가 나한테 뭘 원하는지 모르겠어. |
| 47\. What do you want me to do about it? | 내가 그걸 어떻게 해주길 바라? |
| 48\. I was wondering if you could help me out. | 혹시 좀 도와줄 수 있을까 해서. |
| 49\. Let me know when you're ready to go. | 갈 준비되면 알려줘. |
| 50\. I don't think I can make it on time. | 제시간에 못 갈 것 같아. |
| 51\. I would've done it if I'd known. | 알았더라면 했을 텐데. |
| 52\. I don't know if I should tell you or not. | 너한테 말해야 할지 모르겠어. |
| 53\. How am I supposed to get it done by then? | 그때까지 어떻게 끝내라는 거야? |
| 54\. I didn't know you were going to be here. | 네가 여기 올 줄 몰랐어. |
| 55\. What makes you think I would do that? | 내가 그럴 거라고 왜 생각해? |
| 56\. I thought you said you didn't want to go. | 너 가기 싫다고 하지 않았어? |
| 57\. I don't know how to put it into words. | 어떻게 말로 표현해야 할지 모르겠어. |
| 58\. Is there anything else you want me to do? | 내가 더 해줄 일 있어? |
| 59\. I can't believe you actually went through with it. | 네가 정말 끝까지 실행했다니 믿기지 않아. |
| 60\. If I'd known what it was, I would've told you. | 그게 뭔지 알았더라면 말했을 거야. |


## 집중 훈련할 연결 발음 8개

빠른 미국 영어에서 나타날 수 있는 변화이며, 화자·강세·속도에 따라 달라집니다. 약화를 억지로 만들기보다 들리는 흐름을 따라 연습합니다.

- **did you**: /d/와 /j/가 합쳐져 /dʒ/처럼 들릴 수 있습니다. 3번의 `What did you do?`에서 `did you`를 한 덩어리로 말합니다.
- **would you**: /d/와 /j/가 자연스럽게 이어져 /dʒ/처럼 들릴 수 있습니다. 보충 구절 `Would you help me?`로 연습합니다.
- **want to**: 편한 회화에서 *wanna*처럼 약화될 수 있습니다. 25·56번의 `want to`를 연결합니다. 8번의 `want me to`는 중간에 `me`가 있으므로 *wanna*로 바꾸지 않습니다.
- **going to**: 미래·의도를 나타낼 때 *gonna*처럼 약화될 수 있습니다. 14·54번으로 연습합니다. 장소로 이동하는 `going to school`에는 그대로 적용하지 않습니다.
- **have to**: 의무를 나타내는 구절에서 /v/가 /f/로 무성음화되어 /hæf tə/처럼 들립니다. 보충 구절 `I have to go.`로 연습합니다.
- **if I**: /f/ 뒤에 불필요한 모음을 넣지 않고 /aɪ/로 이어 갑니다. 16·25·28·52번에서 연결합니다.
- **is it**: /z/를 다음 /ɪ/에 이어 붙입니다. 16·20번에서 연습하고, 끝 /t/는 뒤 소리와 강세에 따라 달라지는지 듣습니다.
- **as soon as**: 약한 `as`와 강세를 받는 `soon`의 리듬을 연결합니다. 보충 구절 `as soon as I can`으로 연습합니다.

보충 구절은 연결 설명용이며 위 원문 60문장에는 포함하지 않습니다.

## 짧은 연습법 · 하루 5분

1. **1분 — 고르기:** 오늘의 문장 3개를 고릅니다. 처음에는 Level 2와 Level 4에서 자주 꼬이는 문장을 선택합니다.
2. **2분 — 덩어리 연결:** 느리고 편안한 속도로 연결 구절을 말한 뒤 문장으로 확장합니다. 예: `if I` → `if I should` → `I don't know / if I should tell you or not.` 슬래시는 연습용 의미 덩어리 표시입니다.
3. **1분 — 자연스러운 속도:** 중요한 단어에 강세를 두고 세 번 연속 말합니다. 입이 꼬이면 편안한 속도로 돌아갑니다.
4. **1분 — 랜덤 회상:** 영어를 가리고 한국어 뜻을 보고 말한 뒤 원문을 확인합니다. 어려운 번호를 기록해 다음 날 다시 연습합니다.

한 번 녹음해 단어 사이에 불필요한 모음을 넣는지, 기능어마다 끊는지 확인합니다. 속도보다 편안하게 이어 말하는 것을 목표로 합니다.
