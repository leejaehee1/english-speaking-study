# 모음 음소 · æ, ɛ, ʌ, ɔː, uː, ʊ, ɪ, iː

미국식 영어를 중심으로 **혀의 높이·앞뒤 위치, 입술 모양, 소리의 질**을 비교합니다. 강의 원본이나 단어 목록이 제공된 자료는 아니며, 요청한 여덟 모음의 복습용 정리입니다.

굵은 영어 단어·문장은 눌러 들을 수 있습니다. 기기 음성의 발음은 선택된 목소리에 따라 다릅니다. IPA 기호 자체보다 예시 단어를 듣고 따라 하세요.

## 1. 기호를 읽는 방법

- <strong>/ /</strong>는 음소 표기입니다. 영어 철자 한 글자와 소리 하나가 항상 대응하지 않습니다.
- **ː**는 길이를 나타내는 기호지만, 영어 모음을 단순히 짧게·길게만 나누면 부족합니다. **ship / sheep**, **full / fool**은 혀 위치와 소리의 질도 다릅니다.
- 미국 영어 자료에서는 /iː uː ɔː/를 <strong>/i u ɔ/</strong>로 적기도 합니다. bed의 모음도 사전에 따라 **/ɛ/** 또는 <strong>/e/</strong>로 적습니다. 표기 체계를 확인하세요.
- 실제 길이는 강세·속도·뒤 자음에 따라 달라집니다. 언제나 두 배로 늘이는 규칙은 없습니다.

## 2. 여덟 모음 한눈에 보기

입 모양 설명은 출발점입니다. 턱이나 입술에 과하게 힘을 주지 않습니다.

| 기호 | 혀·입 모양의 기준 | 예시 단어 |
| --- | --- | --- |
| /æ/ | 혀 앞쪽을 낮추고 턱을 비교적 크게 열기. 입술은 둥글리지 않기 | **cat**, **bad**, **salmon** |
| /ɛ/ | 혀 앞쪽. /æ/보다 혀를 높이고 입을 덜 열기 | **bed**, **pen**, **head** |
| /ʌ/ | 혀 중앙 부근을 낮춘 편으로, 입술은 편안하게 펴기 | **cup**, **bus**, **love** |
| /ɔː/ | 구별하는 화자는 혀 뒤쪽을 중간보다 낮게 두고 입술을 둥글리기 | **law**, **saw**, **caught** |
| /uː/ | 혀를 높이고 입술을 둥글리기. 미국 영어에서는 혀가 앞쪽으로 이동한 발음도 흔함 | **food**, **blue**, **moon** |
| /ʊ/ | /uː/보다 혀를 조금 낮추고 중앙 쪽으로. 입술 둥글림은 대체로 덜 강하게 | **foot**, **good**, **book** |
| /ɪ/ | 혀 앞쪽을 높이되 /iː/보다 낮고 중앙 쪽으로. 입술은 둥글리지 않기 | **sit**, **fish**, **milk** |
| /iː/ | 혀 앞쪽을 높이기. 입술은 편안하게 펴고 억지로 활짝 웃지 않기 | **see**, **sheep**, **green** |

### /ɔː/ · 미국식·캐나다식 차이

**cot / caught**를 구별하는 화자도 있고 같은 모음으로 발음하는 화자도 있습니다. 이를 **cot–caught merger**라고 합니다. 북미 영어에서 law, saw, caught가 /ɑ/ 계열로 들릴 수 있으므로 무조건 틀린 소리로 판단하지 않습니다. /ɔː/를 연습할 때는 이를 구별하는 원음과 비교하세요.

### /ʌ/와 /ə/도 구별하기

이 자료의 /ʌ/는 **cup**처럼 강세를 받는 음절에서 연습합니다. about의 첫 모음 <strong>/ə/</strong>는 비강세의 약한 모음입니다. 둘을 단순히 한국어 “어” 하나로 외우지 않습니다. 실제 소리의 유사성은 방언에 따라 달라집니다.

## 3. 헷갈리는 모음 비교

### /æ/ ↔ /ɛ/ · bad / bed

- **bad / bed** — 나쁜 / 침대
- **man / men** — 남자 한 명 / 남자들
- **pan / pen** — 팬 / 펜

bed에서 시작해 혀 앞쪽을 낮추고 턱을 조금 더 열어 bad로 바꿉니다. 길이보다 혀 높이와 입 벌림을 먼저 확인합니다. man처럼 비음 앞의 /æ/는 미국 영어에서 달라질 수 있으므로 bad/bed도 함께 연습하세요.

### /æ/ ↔ /ʌ/ · cap / cup

- **cap / cup** — 모자 / 컵
- **hat / hut** — 모자 / 오두막
- **back / buck** — 등·뒤 / 수사슴·달러(구어)

/æ/는 혀 앞쪽을 낮추고, /ʌ/는 혀를 중앙 부근으로 옮겨 비교합니다. 두 소리를 모두 한국어 “아”로 대체하지 않습니다.

### /uː/ ↔ /ʊ/ · fool / full

- **fool / full** — 바보 / 가득 찬
- **pool / pull** — 수영장 / 당기다
- **Luke / look** — 루크(이름) / 보다

/ʊ/를 길게 늘이기만 해서 /uː/를 만들지 않습니다. 혀 높이·위치와 입술 모양도 바꾸어 원음과 비교합니다. **food / foot**은 끝 자음도 달라 최소대립쌍이 아니므로 소리 예시로만 사용합니다.

### /ɪ/ ↔ /iː/ · ship / sheep

- **ship / sheep** — 배 / 양
- **sit / seat** — 앉다 / 좌석
- **live / leave** — 살다 / 떠나다. live는 여기서 동사 /lɪv/입니다.

/ɪ/는 /iː/보다 혀를 조금 낮추고 중앙 쪽으로 둡니다. sit을 오래 말하는 것만으로 seat가 되지 않습니다.

## 4. 음식 표현으로 문장 연습

- **The salmon is fresh.** — 연어가 신선해요. salmon의 /æ/, fresh의 /ɛ/. salmon의 l은 묵음입니다.
- **The cup is full.** — 컵이 가득 차 있어요. cup의 /ʌ/, full의 /ʊ/.
- **The soup is too hot.** — 수프가 너무 뜨거워요. soup와 too의 /uː/.
- **The fish is good.** — 생선이 맛있어요. fish의 /ɪ/, good의 /ʊ/.
- **The green beans are ready.** — 그린빈이 준비됐어요. green·beans의 /iː/, ready의 첫 모음 /ɛ/.
- **I saw the menu.** — 메뉴를 봤어요. saw는 /ɔː/와 /ɑ/ 계열의 방언 차이를 확인합니다.

문장 전체를 자연스럽게 말한 뒤 목표 단어만 비교합니다. 문장 안의 모든 모음을 똑같이 길고 강하게 발음하지 않습니다.

## 5. 하루 5분 복습

1. **1분:** 대표 단어 cat, bed, cup, saw, food, foot, sit, see 듣고 따라 하기.
2. **2분:** bad/bed, cap/cup, fool/full, ship/sheep를 각각 세 번. 가능하면 상대가 들은 단어를 맞히게 하기.
3. **1분:** 음식 문장 두 개를 녹음하기.
4. **1분:** 헷갈린 한 쌍만 다시 듣고 혀 위치·입술 모양을 조절하기.
