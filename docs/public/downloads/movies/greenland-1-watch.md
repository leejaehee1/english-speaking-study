## 시간 맞추기

시간은 사용자가 제공한 영어 SRT의 원본 시간입니다. **영상과의 동기화는 아직 확인하지 않았으며 보정값을 적용하지 않았습니다.** 한글 SMI와도 시간 기준을 섞지 않았습니다.

표시 시간은 chunk 자체의 정확한 음성 시작점이 아니라, 그 표현이 들어 있는 자막 항목의 시작점입니다. 2–3초 전부터 재생해 확인합니다. 60분 이후는 60:00, 70:00처럼 누적 분으로 표시합니다.

## 듣기 포인트

먼저 한 구간에서 A 표현 3–5개를 고릅니다. 뜻을 확인한 뒤 자막 없이 듣고, 단어가 아니라 덩어리로 따라 말합니다. 안 들린 부분은 상세 복습에서 축약·연결 가능성을 확인하고 실제 영상과 비교합니다.

- **gotta / gonna / 'em / outta:** 작은 음절로 줄어든 형태를 원래 구조와 연결합니다.
- **must've / should've / How'd / that'll:** 생략된 have·did·will을 복원해 이해합니다.
- **got it all / give it a / made it:** 자음과 모음이 이어지는 경계를 듣습니다.
- **take off / work out / go through:** 같은 표현도 장면에 따라 뜻이 달라집니다.
- **can't / won't / didn't:** 끝 자음만으로 부정을 판단하지 않고 강세·문맥도 확인합니다.
