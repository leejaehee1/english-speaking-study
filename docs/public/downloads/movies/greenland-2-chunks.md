# Greenland 2: Migration — 시간순 회화 chunk 학습 가이드

- 출처: 사용자가 첨부한 `Greenland.2.Migration.2026.srt`. SRT 805개 항목, 00:00:00,000–01:32:02,600. 영화 영상 길이가 아닌 **자막에 기록된 범위**다.
- 선별: **129개**, 첫 대사부터 마지막 대사 구간까지 시간순. 원문 chunk는 자막의 연속 문자열과 자동 대조했다. 같은 자막에서 두 표현을 고른 경우도 있다.
- 타임코드는 chunk만의 음성 시작·끝이 아니라 **그 표현을 포함하는 SRT 항목 전체 구간**이다. 플레이어에서 2–3초 앞으로 이동해 듣는다. 다른 영상판에서는 시간차가 날 수 있다.
- **A**: 일상 재사용성이 높아 먼저 학습 / **B**: 유용하지만 상황 의존 / **C**: 격식·문학·강한 감정 표현. 빈도 통계나 난도 점수가 아니다.
- 영화에는 여러 국적·억양의 인물이 등장한다. 여기서는 미국 영어 회화에도 쓸 수 있는 표현을 골랐다. 배우의 미국식 발음을 확인했다는 뜻은 아니다.
- **발음/연음은 음성 미확인 상태의 일반적인 미국 영어 가능형**이다. 실제 축약·강세·억양은 영상을 듣고 확인한다. /ɾ/는 혀끝을 한 번 가볍게 치는 소리이며 한국어 ㄹ과 완전히 같지는 않다. 부정어는 끝소리만으로 판단하지 말고 문맥과 강세도 듣는다.
- 사용 맥락은 인접 자막으로 판단한 장면 수준의 설명이다. 화자 정보는 SRT에 없어 임의로 붙이지 않았다. 줄거리에 대한 스포일러가 포함된다.

## 자막 품질 주의

자막을 정답 대본으로 간주하지 않는다. 예를 들어 #25의 “I'd turn my left arm”이나 #402의 “second wife”, #789의 “beat you”는 전사 오류일 가능성이 있어 핵심 학습 목록에서 제외했다. 실제 음성을 확인하지 않고 다른 대사로 고치거나 복원하지 않았다. 문장이 끊기거나 의미가 불명확한 다른 항목도 선별에서 제외했다. #253의 anymore, #650의 up -to -date처럼 선택한 항목의 표기도 원문대로 유지하고 필요한 설명만 덧붙였다.

## 날짜별 누적 템플릿

CSV의 원본 열은 유지하고 학습 열만 채운다. 같은 표현을 다시 만나면 기존 ID에 복습 날짜를 갱신한다. 새 영화는 자료 접두어를 달리해 ID가 겹치지 않게 한다.

```markdown
# YYYY-MM-DD 학습 기록
- 자료 / 시청 구간:
- 오늘 수집한 ID:
- 오늘 집중할 ID (3–5개):
- 안 들린 이유: [뜻을 모름 / 단어 경계 / 약화·연음 / 속도 / 기타]
- 실제로 들린 소리와 자막의 차이:
- 자막 없이 뜻을 떠올린 표현:
- 내 상황으로 바꿔 말한 문장 (직접 만든 예문임을 표시):
- 다음 복습일:
```

### 짧은 복습 루틴

1. **당일**: 3–5개 선택 → 뜻 확인 → 5–10초 구간을 자막 없이 듣기 → 자막 확인 → 2–3회 따라 말하기 → 자막 없이 다시 듣기.
2. **다음 날·3일 뒤·7일 뒤·14일 뒤**: 영어를 가리고 한국어 뜻으로 chunk 말하기, 이어서 해당 음성을 자막 없이 듣기. 단순히 읽어서 아는지와 실제로 들리는지를 따로 점검한다.
3. 알아듣고 자기 상황에서도 말할 수 있으면 `익숙함`, 뜻은 알지만 음성에서 놓치면 `듣기복습`, 처음 접하면 `미학습`으로 표시한다. 다시 놓치면 다음 날 재확인한다.
4. CSV의 `added_date`, `last_review`, `next_review`는 YYYY-MM-DD로 입력한다. 일정은 제안이며 자동 계산되지 않는다. 많이 모으는 날에도 집중 복습량은 별도로 작게 유지할 수 있다.

### CSV 열 안내

`id`: 고정 학습 ID / `section`: 10분 구간 / `cue`: SRT 번호 / `start`, `end`: 원본 타임코드 / `chunk`: 원문 표현 / `meaning_ko`: 한국어 뜻 / `context_ko`: 장면과 용법 / `pronunciation_ko`: 일반 미국 영어 예상 발음 / `priority`: A·B·C / `source_text`: 해당 SRT 전체 텍스트 / `added_date`, `status`, `last_review`, `next_review`, `listening_note`, `my_sentence`: 누적 학습 기록.

CSV는 한국어가 잘 보이도록 UTF-8 BOM으로 저장했다. 자막 출처 문장과 직접 만든 예문은 각각 `source_text`와 `my_sentence`로 구분한다.
