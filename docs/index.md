# English Speaking Study

**목표: 밴쿠버에서 쉬운 일상 대화를 편하게 하기.**

2개월 동안 평일에 연습합니다. 주문하기, 길 묻기, 짧은 안부 대화부터 시작합니다.

## 오늘 할 일

1. 표현 3개를 내 상황으로 바꿔 말하기
2. 노트 한 페이지 정도를 원어민 음성처럼 녹음해 **자정까지 카카오톡 제출**
3. 영어 일기를 쓰고 교정한 뒤 **공책에 필사**

녹음과 필사는 서로 다른 내용이어도 됩니다. 녹음 파일은 따로 보관하지 않습니다.
