# English Speaking Study

2개월 동안 **평일에 말하고, 짧게 기록하고, 다시 써먹는** 영어회화 노트입니다.

## 나의 목표 · 밴쿠버 일상 대화

외국, 특히 밴쿠버에서 일상생활에 필요한 쉬운 대화를 편하게 주고받는 것이 목표입니다.

- 카페·식당에서 주문하고 요청 사항을 말하기
- 장을 보며 물건 위치와 가격 묻기
- 길·버스·교통편을 묻고 답을 확인하기
- 이웃이나 처음 만난 사람과 날씨·주말·취미 이야기하기
- 잘 못 들었을 때 다시 묻고, 필요한 것을 다른 말로 설명하기

2개월 동안의 확인 기준: 익숙한 상황에서 노트를 보지 않고 질문·답변·추가 질문을 3–5번 주고받기. 실수가 있어도 필요한 말을 하고, 이해가 안 되면 확인하며 대화를 이어갑니다.

## 학습 규칙

- 하루 기록은 5분 이내: 핵심 표현 3개, 내 문장 3개, 교정 1개만 남깁니다.
- 날짜별 기록은 `daily/`, 다시 쓸 표현은 `patterns/`, 반복 오류는 `mistakes/`에 모읍니다.
- 표현은 읽고 끝내지 않고 내 상황으로 바꿔 소리 내어 말합니다.
- 다음 날과 금요일에 노트를 가리고 다시 말합니다. 주말은 선택 복습입니다.

## 숙제 기록 방식

- **녹음 숙제**: 노트 한 페이지 정도를 원어민 음성의 발음·강세·리듬에 가깝게 연습하고, 당일 자정까지 카카오톡으로 제출합니다. 사이트에는 참조 자료, 연습 범위, 제출 여부만 남깁니다.
- **필사**: 영어 일기를 작성하고 교정한 뒤 공책에 옮겨 씁니다. 일기 외에 참조 스크립트나 다른 글을 필사해도 됩니다. 사이트에는 내용과 공책 페이지, 완료 여부를 기록합니다.
- 녹음과 필사는 같은 내용을 사용해도 되고, 서로 달라도 됩니다.
- [영어 일기](./diary/index.md)와 [원어민 참조 자료](./references/index.md)는 따로 모으고, Daily에서 연결합니다.

## 기본 연습 루틴 · 25분

숙제에 필요한 시간은 분량에 맞춰 별도로 확보합니다.

1. 어제 표현 3개를 보지 않고 말하기 · 5분
2. 오늘 패턴으로 내 문장 3개 만들기 · 10분
3. 짧은 음성 따라 말하기 또는 1분 녹음 · 5분
4. Daily 기록과 교정 · 5분

## 2개월 방향

- 1–2주: 자기소개·인사·카페 주문, GET / MAKE / HAVE / LET
- 3–4주: 장보기·길 묻기·버스 이용, 들은 내용 확인하기
- 5–6주: 날씨·주말·취미로 짧은 대화, 간단한 예약과 요청하기
- 7–8주: 밴쿠버 생활 상황 역할극, 추가 질문으로 대화 이어가기, 반복 실수 복습

매주 한 상황을 골라 손님과 직원 또는 이웃 역할을 번갈아 연습합니다. 녹음 숙제의 발음 연습과 함께, 문장을 보지 않고 직접 답하는 연습도 합니다.
