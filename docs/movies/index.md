## 매일 쌓는 방법

수집량은 자유롭게 정하고, 집중 복습은 하루 3–5개를 고릅니다. 당일 → 다음 날 → 3일 뒤 → 7일 뒤 → 14일 뒤에 자막 없이 듣고, 내 상황으로 바꿔 말합니다.

- [날짜별 기록 양식](./study-template.md)
- [빈 복습 CSV](/downloads/movies/daily-review-template.csv)

새 영화도 시청용·상세 복습·학습 CSV로 나눕니다. 영상과 자막의 시간차는 영화마다 확인하고 원본 시간은 유지합니다.
