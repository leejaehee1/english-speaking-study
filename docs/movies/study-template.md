# 날짜별 학습 양식

아래 내용을 복사해 날짜별로 기록합니다.

```markdown
# YYYY-MM-DD · 영화 제목
- 시청 구간:
- 자막 시간 → 영상 시간 확인 대사:
- 시간 보정값 / 적용 구간:
- 오늘 수집한 표현 ID:
- 집중 복습할 3–5개:
- 안 들린 이유: 뜻 / 단어 경계 / 연음·약화 / 속도
- 실제로 들린 소리:
- 직접 만든 내 문장:
- 복습 결과 / 다음 복습일:
```

직접 만든 예문은 영화 원문과 구분합니다. 원본 SRT 시간과 보정 시간도 별도로 보관합니다. CSV의 학습 날짜·복습일은 직접 입력합니다.
