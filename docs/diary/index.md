# 영어 일기

내 일상을 짧은 영어로 작성하고, 교정한 문장을 공책에 필사합니다.

## 작성 순서

1. 오늘 있었던 일이나 생각을 영어 3–5문장으로 적습니다.
2. 교정 전과 교정 후를 구분하고, 배운 표현 1개를 남깁니다.
3. 교정된 일기를 공책에 옮겨 쓰고 Daily에 공책 페이지와 완료 여부를 표시합니다.

일기에는 실제 일상과 함께, 밴쿠버에서 같은 상황이라면 할 말 1문장을 선택해서 적어봅니다. 예: 주문하기, 길 묻기, 주말 이야기.

녹음 숙제에는 별도의 원어민 스크립트를 써도 됩니다. 실제 일기 내용은 직접 작성합니다.
