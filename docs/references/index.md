# 원어민 참조 자료

녹음 숙제에 사용할 스크립트와 원어민 음성 출처를 모읍니다. 일기와는 별도로 관리합니다.

## 자료 추가 방법

1. [스크립트 기록 양식](./script-template.md)을 복사해 자료별 파일을 만듭니다.
2. 카페·장보기·길 묻기·이웃과의 대화처럼 목표에 맞는 일상 자료를 우선 고르고, 제목·원문 출처·원어민 음성 링크와 구간을 기록합니다.
3. 노트 한 페이지 정도의 연습 범위를 정하고, 강세·리듬에서 따라 할 점 1개를 적습니다.
4. 이 목록과 사이드바에 자료 링크를 추가하고 Daily의 녹음 숙제에서 연결합니다.

스크립트는 직접 제공받은 자료나 사용 가능한 텍스트를 기록합니다. 원문을 옮기기 어려우면 출처 링크와 연습 구간만 남겨도 됩니다. 녹음 파일은 카카오톡으로 제출합니다.
